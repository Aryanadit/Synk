🧠 2. PRIMARY DESIGN SHIFT (IMPORTANT)

NEW (correct):

🎨 3. COLOR SYSTEM (PREMIUM FIX)
❌ REMOVE THIS:
“Color on hover everywhere”
“Accent usage too frequent”
✅ NEW RULE:

Color is rare. Interaction is mostly grayscale.

Final Color Behavior:
State	Behavior
Default	Pure neutral
Hover	Slight gray shift (NOT accent)
Active	Accent appears
Focus	Very soft ring
Accent Usage:
Only for:
Active conversation
Primary button
Focus states

👉 NOT for hover
👉 NOT for decoration

🔤 4. TYPOGRAPHY (THIS IS YOUR PREMIUM ENGINE)
Upgrade this mindset:

Typography > Color > UI elements

Rules:
Body: 15px ✔
Line height: 1.6 ✔
Font weight:
Normal → 400
Emphasis → 500/600 (rare)
❌ Avoid:
Too many font sizes
Bold everywhere
Colored text hierarchy
🔥 Premium Rule:

If UI looks bad → fix spacing or typography, NOT colors

📐 5. SPACING (MOST IMPORTANT CHANGE)

This is where premium comes from.

New Rule:

Everything breathes more than you think it should

Values:
Chat padding → 28–32px (increase from 24)
Sidebar → 16px (keep clean)
Message gap → 12–16px
🔥 Rule:

Tight UI = cheap UI

💬 6. CHAT SYSTEM (MAJOR PREMIUM FIX)
❌ REMOVE:
Discord-like visual noise
Hover background on every message
✅ NEW DESIGN:
Messages:
Flat
No background by default
No borders
Pure text layout
On hover:
VERY subtle gray (barely visible)
Actions appear quietly
🔥 Key Shift:

Messages should feel like reading a document, not interacting with components

🛠️ 14. MASTER PROMPT (PREMIUM)

Use THIS instead now:

Follow Synk Design System v6:

- Prioritize calm, minimal UI (Notion-like)
- Use grayscale by default, avoid unnecessary colors
- Show interactions subtly, not aggressively
- Use color only for active/focus states
- Prefer spacing over borders and components
